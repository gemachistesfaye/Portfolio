# ⚡ Gemachis Tesfaye — Portfolio

Modern, dark-themed developer portfolio with smooth animations, a CMS blog, and responsive design.

🔗 **Live:** [gemachisdev.vercel.app](https://gemachisdev.vercel.app/)

---

## ✨ Features

- 🎨 Dark mode with glassmorphism & gradient effects
- 📱 Fully responsive with slide-in mobile nav
- 📝 Blog powered by Sanity CMS
- 📩 Contact form with FormBlade
- 💼 Floating "Hire Me" modal
- 🔍 SEO optimized (sitemap, RSS, Open Graph)
- 🎬 Scroll-triggered animations
- 📄 One-click CV download

---

## 🛠 Tech Stack

React 18 · Vite 6 · Tailwind CSS 3 · React Router 7 · Sanity · Lucide Icons · Vitest

---

## 🚀 Quick Start

```bash
git clone https://github.com/gemachistesfaye/Portfolio.git
cd Portfolio
npm install
cp .env.example .env   # fill in your values
npm run dev             # → http://localhost:5173
```

### 📦 Scripts

| Command | What it does |
|---------|-------------|
| `npm run dev` | 🟢 Dev server |
| `npm run build` | 📦 Production build |
| `npm run test` | 🧪 Run tests |
| `npm run build:all` | 🔄 Build + RSS |

---

## 🌐 Deploy on Vercel

1. Push to GitHub → connect to [Vercel](https://vercel.com)
2. Add env vars (see `.env.example`)
3. Deploy 🚀
